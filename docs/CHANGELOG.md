## [Unreleased] — v0.3.1 收藏与筛选稳定性修复

### 修复
- 修复首页文章卡片的“收藏”按钮此前没有点击事件的问题：登录用户现在可以收藏和取消收藏，按钮会显示当前状态并提供操作反馈。
- 收藏与文章点赞分离，收藏记录按用户 ID 独立保存于当前浏览器 localStorage；访客点击收藏会提示登录并跳转登录页。
- 修复标签筛选后文章卡片重复执行按索引延迟的入场动画、造成列表上下位移抖动的问题。筛选结果变化不再触发卡片入场动画。
- 收藏存储模块处理损坏数据、无效参数和浏览器存储异常，避免操作失败时静默无反馈。

### 测试
- 新增收藏纯函数测试：覆盖收藏、取消收藏、刷新后读取、不同用户隔离、损坏数据与无效参数。
- 本次 CI 结果待 GitHub Actions 完成后补录；未完成前不宣称测试或构建通过。

### 说明
- 收藏数据仍是本地演示数据，不同步云端，不同浏览器/设备不共享；正式 Supabase 收藏功能需后续设计数据库表和 RLS。
- 本次未修改数据库结构，也未把收藏混同为点赞。

## [Unreleased] — v0.3.1 体验修复与后台管理优化

### 新增
- 首页筛选面板：支持分类、标签和排序条件，并可与关键词搜索组合。
- 首页分类导航和热门标签增加明确的选中状态与可操作按钮。
- 管理后台文章表格支持关键词搜索、状态筛选、排序、分页（每页 10/20/50 条）、单篇删除和批量删除。
- 新增可复用文章筛选、排序、分页纯函数及对应 Node 单元测试。

### 修复
- 修复首页快速导航分类项和热门标签只是静态展示、点击无效的问题。
- 修复首页搜索框旁筛选图标没有点击行为的问题。
- 修复首页筛选结果未组合计算、清除筛选反馈不足的问题。
- 首页和管理后台的关键词搜索均支持匹配标签名称，而不只是标签 ID。
- 管理后台从无分页的纵向文章列表改为紧凑表格，降低大量文章时的浏览和定位成本。
- 修正管理后台数据刷新逻辑，避免新增 React Hook 依赖警告。
- 明确首页权限说明：访客阅读公开文章、作者管理自己的文章、编辑/管理员按权限管理全站内容。

### 验证
- GitHub Actions（提交 60201876f3c1）：依赖安装通过。
- `npm test`：10/10 项测试通过。
- `npm run build`：通过。
- `npm run lint`：未通过，仍报告 8 个错误、9 个警告；与 v0.3.0 主分支基线数量一致，本次修改文件未新增 lint 错误或警告。遗留问题集中在既有 Profile、UI 组件、QQ 音乐服务和 Tailwind 配置文件。
- 首次 CI 曾发现分页测试断言未使用排序后的输入，已修正测试后重新验证通过。

### 说明
- 当前版本仍是本地演示环境，文章与用户数据保存在浏览器本地。
- 管理后台删除操作仍为本地永久删除；当前文章模型没有软删除字段，因此本版本不展示回收站/恢复入口。
- 尚未完成真实浏览器手工验收；请项目负责人下载分支 ZIP 后体验首页筛选和管理员列表。
